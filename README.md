# Steam Games Analytics

## Overview

This project analyzes more than 10,000 Steam games to identify popularity patterns, player engagement, review quality, and publisher performance.

## Objectives

- Data cleaning and preprocessing
- Missing values analysis
- Outlier detection
- Feature engineering
- Exploratory Data Analysis (EDA)
- Visualization of player behavior

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Findings

- Identified the most played games on Steam.
- Analyzed review quality through positive review ratios.
- Detected significant outliers in player engagement.
- Compared developers and publishers by popularity metrics.
